
Adds configuration options to adjust the rate of natural phenomenon like Beehives and Fruit Tree vernalization (Some features to come, all current commands listed).

    /fasternature beehivespeedrate [rate]

The rate is a value from .01 to 100. A rate of .01 means the structures will work in 1/100th the amount of time, 100 would be 100 times slower, and 1 would be the normal default value. Using one of the available commands without a rate will show the current value. 

There is also a configuration file that will save your current rates in ~/ModConfig/FasterNature/FasterNature.json
